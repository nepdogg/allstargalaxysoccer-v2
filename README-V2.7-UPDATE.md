# Allstar Galaxy V2.7 — Universal Masthead & Footer Lockdown

This release applies the final shared-framework refinements requested after V2.6.

## Shared public changes
- Complete identity/title/navigation/status masthead is sticky as one unit.
- Accent rail is visible at the very top of the page shell.
- Galaxy background is painted reliably on both `html` and `body`.
- Status message and OPEN link are centered together.
- Hero receives a thin accent separator below the status module.
- Footer contact control sits directly beneath the mini navigation.
- Administration remains in the same footer navigation row.
- Social icons use platform-specific hover glows.
- A miniature Allstar Galaxy logo appears beside the copyright line.

## Administration changes
- Administration identity, navigation, and status are sticky together.
- Administration status content is centered as a group.
- Administration logos retain the shared pulse behavior.

## Deployment
Copy the full repository contents into the local GitHub Desktop repository, replace matching files, commit, and push. Hard-refresh the live site after GitHub Pages finishes rebuilding.
