# Allstar Galaxy V2.8 — Balanced Galaxy Frame Update

This release refines the universal shared framework.

## Changes

- Restores the galaxy background through a dedicated fixed backdrop element.
- Adds matching inset top and bottom accent rails with identical viewport gaps.
- Balances the public status bar with mirrored stars and OPEN links.
- Applies the same status-bar balance and galaxy backdrop to Administration.
- Keeps the complete public and Administration mastheads sticky with an 8px top gap.
- Updates the displayed release version to V2.8.

## Safe installation

Copy the complete repository contents over the existing local repository, commit, push, wait for GitHub Pages to rebuild, and hard-refresh the browser.
