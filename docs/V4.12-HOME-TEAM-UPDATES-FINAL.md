# V4.12 Home / Team / Updates Final Interaction Lock

This update finalizes the shared popup interaction pattern for the completed Home, Team and Updates work.

## Updates
The four vertical live update cards keep their current layout. Clicking Schedule, Results, Standings or Latest News opens a centered green modal styled to match the established Team modal language. Uploaded graphics are shown fully contained and uncropped. Empty modules use a properly proportioned placeholder rather than a narrow vertical box. Previous and next arrows cycle through the four modules without closing the viewer.

## Team
The existing dual Front Card + Profile Card viewer is retained. Its previous and next controls continue browsing players while the modal stays open, and the underlying roster carousel is now synchronized to the player being viewed.

## Home
No Home layout or behavior was changed.
