# Allstar Galaxy V4.8 — Team Original Carousel Hybrid

This update changes only the Team roster carousel presentation.

## Restored from the original Team carousel
- Wider carousel footprint that reaches closer to the page edges.
- Larger, more readable player-card proportions.
- Stronger layered/overlapping roster depth.
- Up to three visible roster positions on each side on large desktop screens.

## Kept from the newest Team page
- Current dual Front Card + Profile Card player popup.
- Full-size Front Card and Profile Card viewers.
- Current live Team Stats section and interactions.
- Current universal framework and page styling.

## New improvement
Every visible roster card now has hover/focus glow feedback, including the current center card. The center card also has a permanent stronger glow so the currently selected player is always obvious.

No Home-page or universal-framework design files were intentionally changed beyond the Team page files included in this update.
