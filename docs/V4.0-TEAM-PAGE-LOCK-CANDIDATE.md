# Allstar Galaxy V4.0 — Team Page Lock Candidate

Team-page-only update. Universal header, navigation, status bar, hero framework, galaxy background and footer are not modified.

## Changes
- Tightens the roster carousel to restore the original stacked/overlapping cover-flow appearance.
- Shows active + two neighboring players on each side on desktop, with stronger depth and less empty vertical space.
- Moves carousel arrows closer to the card stack.
- Keeps Front Card and Profile Card equal-size in the player viewer.
- Expands the Profile Card name into the full name window with automatic long-name sizing.
- Expands the player quote across the complete lower quote panel with automatic text sizing.
- Keeps profile values aligned to the five printed detail rows.
- Featured Player is now automatic/random from published roster players on every page visit and avoids repeating the previous selection when possible.
- Team Stats cards remain generated from master-content.json and are now interactive navigation cards.
- No manual Featured Player maintenance is required.

## Suggested Team-page lock test
1. Desktop 100% zoom: roster carousel should look compact and layered.
2. Click several players and verify both card faces are equal-size.
3. Verify short and long player names stay inside the Profile Card name area.
4. Verify short and long quotes fill the lower Profile Card quote area without escaping it.
5. Refresh Team page several times and confirm Featured Player changes.
6. Test all six Team Stats cards.
7. Test desktop and phone before declaring Team page locked.
