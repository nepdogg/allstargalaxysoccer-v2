# Allstar Galaxy V4.7 — Home / Team / Universal Framework Lock

This cumulative update-only package finalizes the shared framework plus the Home and Team visual systems.

## Universal framework
- 10 reserved hero slots on every public page.
- Visitors only see dots for populated hero images.
- Shared hero auto-rotation, pause-on-hover/focus, swipe navigation, and reduced-motion support.
- Team submenu no longer contains the redundant Player Profiles link.
- Site-wide rotating status architecture and working social URLs retained from V4.6.

## Home
- Six live cards remain data-driven and fully clickable.
- Standardized crisp inline SVG icons replace mixed symbol styles.

## Team
- Front-card name/position safe regions refined to prevent clipping.
- Profile-card name block centered in its full printed name space.
- Quote uses and centers within the complete printed quote zone.
- Six live Team Stats cards receive standardized upper-right SVG icons.
- Stats action labels are white at rest and turn purple on whole-card hover/focus.
- Existing live stats, random Featured Player, dual-card player viewer, and detail popups remain intact.

No large graphics are included. Copy this package over the current V4.6/V2 repository and replace matching files.
