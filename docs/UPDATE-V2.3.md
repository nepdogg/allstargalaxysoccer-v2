# Allstar Galaxy V2.3 Update

This release restores the visual atmosphere and completes the universal page framework.

## Included

- galaxy background visible behind every page
- translucent, page-colored glass content shell
- shared floating translucent footer
- status bar without vertical side borders
- brighter opposite-direction top and bottom energy rails
- reorganized Team and Explore dropdown menus
- full standard 404 page with recovery actions
- documented shared CSS, JavaScript, JSON, and page architecture

## Installation

This package intentionally excludes the image library. Copy its contents over the
existing repository root. Keep the current `assets/` folder in place.
