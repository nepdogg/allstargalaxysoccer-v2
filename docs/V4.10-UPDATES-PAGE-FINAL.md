# V4.10 Updates Page Final

Four full-width vertical live modules: Schedule, Results, Standings, Latest News.

- Updates submenu now maps directly to #schedule, #results, #standings, #latest-news.
- Each module supports an uploaded graphic preview using object-fit: contain (never cropped).
- Clicking a populated card opens the same graphic in a large lightbox.
- Lightbox supports previous/next, Escape, backdrop close, and phone pinch zoom.
- Every module displays an UPDATED timestamp.
- Optional NEW/UPDATED badge.
- Green page accent, icon glow, lift/hover, and white-to-green CTA behavior.
- Data-driven structure prepared for Administration editing.
- Hidden/draft modules are not rendered; order is data-controlled.
