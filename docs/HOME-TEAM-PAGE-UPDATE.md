# Allstar Galaxy V2 — Home Final + Team Restoration

## Locked shared framework
This update does not modify the universal header, navigation, latest-update status bar, hero framework, galaxy background, footer, or section-color system.

## Home page
Home remains in its finalized lightweight form:

Hero carousel → Explore the Allstar Galaxy → six guided-navigation cards → footer.

No Latest Games carousel is included on Home. Latest Games remains available through its Explore card and the Media page.

## Team page
The Team page now restores the visual roster experience inside the V2 purple Team module:

- data-driven player-card carousel
- previous/next controls
- swipe support on touch screens
- player position dots
- player profile viewer with previous/next navigation
- six live Team Stats cards generated from master-content.json
- responsive desktop/tablet/phone layouts

Only Team-specific CSS/JavaScript and the two player-card template graphics were added/changed.
