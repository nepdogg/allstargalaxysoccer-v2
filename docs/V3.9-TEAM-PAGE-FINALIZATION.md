# Allstar Galaxy V3.9 — Team Page Finalization

Team-only update. The locked universal framework is not changed.

## Roster carousel
- Compact container sized around the cards.
- Circular cover-flow so cards wrap around and are visible on both sides.
- Desktop shows active player plus two progressively smaller players on each side.
- Arrows stay closer to the card group.
- Phone reduces to active player plus immediate neighbors.

## Player viewer
- Front Card and Profile Card use the same display width and height.
- Profile template labels are no longer duplicated by HTML overlays.
- Data values are aligned to the five printed template rows.
- Player quote is rendered inside the Profile Card.
- Clicking either card still opens the full-card lightbox.
- Original player photo remains available as a secondary link.
