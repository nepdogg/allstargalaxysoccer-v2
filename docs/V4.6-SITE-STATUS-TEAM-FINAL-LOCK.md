# Allstar Galaxy V4.6 — Site Status + Team Final Lock

## Shared site update
- Status bar now rotates three message types on every public page:
  1. global latest game/video update,
  2. global next-game update (automatic when a published upcoming match exists),
  3. a current-page-specific message.
- The center status sentence remains the only clickable link.
- Existing top/bottom energy rails remain opposite-direction animations.
- If no next game has been published yet, the NEXT message links visitors to Updates rather than showing blank data.

## Team page final visual polish
- Team Stats action text is white at rest and turns Team purple on whole-card hover/focus, matching the Home Explore interaction language.
- Removed the extra border/background around the front-card player position.
- Profile-card first/last name group is vertically and horizontally centered in the full printed name area.
- Profile quote uses the complete quote zone with centered, naturally wrapped text.
- Increased safe spacing between Team Stats intro copy and hoverable cards.
- Increased stats-row visual weight to use the card space better.
- Rebalanced the random Featured Player image so it does not cover player copy or OPEN PROFILE.

## Framework rule
No header/footer/page layout redesign was performed. This release is intended as a framework/status finalization plus Team visual lock candidate.
